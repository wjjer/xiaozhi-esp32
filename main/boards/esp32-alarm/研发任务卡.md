# ESP32-Alarm P0 研发任务卡

## 项目目标

在 `esp32-alarm` 板上完成一版可演示、可联调、可继续扩展的儿童 AI 学习陪伴闹钟 P0。

## P0 范围

- 首页、应用网格、AI、学习、闹钟、工具六大入口
- 闹钟、倒计时、秒表、专注时间、夜灯
- AI 聆听 / 思考 / 回答基础闭环
- 学习类入口占位页
- Wi-Fi + ML307C 网络状态展示
- 触摸 + 语音基础交互

## 重要修复记录

### 2026-05-08: UI 宏保护修复

**问题描述**：
`ESP32_ALARM_USE_NEW_UI` 宏用于将 esp32-alarm 板的新 UI 与其他板子隔离，但部分文件缺失宏保护，导致非 esp32-alarm 板编译报错。

**受影响的文件**：
1. `main/display/lcd_alarm_ui.cc` - 直接 include UI 头文件和调用 UiSystem 方法
2. `main/display/lcd_time_tools_ui.cc` - 直接调用 UiSystem 方法

**修复内容**：
1. 为 `lcd_alarm_ui.cc` 添加 `#if defined(ESP32_ALARM_USE_NEW_UI)` 宏保护
2. 为 `lcd_time_tools_ui.cc` 的 `SetupTimerScreen()`、`SetupStopwatchScreen()`、`SetupFocusScreen()` 函数添加宏保护

**验证结果**：
- ✅ 所有 P0 接口清单中的 UI 接口均已实现
- ✅ 宏保护修复完成，非 esp32-alarm 板可正常编译

## 角色任务

### 前端

- 以 `ui_designer/alarm/alarm.guiguider` 作为唯一布局来源
- 将 GUI Guider 导出代码放入 `ui_generated/`
- 固件侧不再新增手写 LVGL 页面坐标
- 首页、AI、学习、闹钟、天气、倒计时、秒表、专注、夜灯先完成生成控件接入
- 学习页保留查词、生词本、背单词、K12 入口，并显示“待接入”
- 旧手写 LVGL 页面在迁移完成后删除或隔离

### 板级

- `esp32-alarm` 板级宏和默认配置收口
- LCD、背光、触摸、音频、LED、网络初始化跑通
- 触摸接入 LVGL indev
- 网络事件桥接到状态栏和首页
- 首页时钟每秒刷新

### 业务

- 闹钟数据结构与本地保存
- 闹钟列表、新建、编辑、删除
- 响铃、停止、小睡
- 倒计时、秒表、专注时间基础逻辑
- AI 交互三态和失败提示

### 联调

- 统一页面路由和状态流转
- 首页、应用网格、功能页、占位页跳转顺畅
- 网络切换时状态栏和首页文案同步
- AI / 闹钟 / 通知 / 弹窗共用同一套状态出口

## 接口边界

- 板级向 UI 暴露：`SetNetworkEventCallback(...)`、`AttachTouchHandle(...)`、`SetHomeTime(...)`、`SetHomeStatus(...)`
- UI 向业务暴露：`NavigateTo(route)`、页面刷新、通知提示、返回首页
- 业务向 UI 暴露：闹钟状态、AI 状态、计时状态、失败状态
