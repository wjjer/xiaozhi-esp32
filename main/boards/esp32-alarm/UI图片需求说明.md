# ESP32-Alarm UI图片需求说明（横屏版）- 320×240

## 一、设计原则（横屏优化）

1. **儿童友好**：明亮色彩、圆角设计、大图标
2. **横屏优势**：充分利用320宽度，展示更多信息
3. **分区布局**：左右分区，信息层级清晰
4. **触摸友好**：触摸区域最小48×48像素
5. **视觉平衡**：横屏视觉重心平衡，避免头重脚轻

## 二、屏幕规格与布局

**物理尺寸**：320×240像素，横屏模式（宽320，高240）
**可用区域**：320×216像素（扣除顶部状态栏24像素）
**安全边距**：四周各5像素，实际内容区域310×206像素
**设计网格**：使用8像素网格系统，确保对齐

## 三、核心设计理念（横屏特色）

### 1. **左右分区设计**
```
┌─────────────────────────────────────────────────────────────┐
│ 左区：主要功能/信息区             右区：辅助功能/控制区     │
│                                                             │
│  - 大时钟显示                    - 快速入口图标            │
│  - 主要信息卡片                  - 状态卡片               │
│  - 核心操作区域                  - 快捷操作按钮           │
└─────────────────────────────────────────────────────────────┘
```

### 2. **横向信息流**
- **首页**：左时钟右入口，信息并行展示
- **列表页**：横屏可显示更多列，减少滚动
- **详情页**：左右并排显示相关信息

### 3. **触摸热区优化**
- 图标尺寸：最小64×64像素
- 按钮尺寸：最小80×40像素
- 间距：图标间至少16像素
